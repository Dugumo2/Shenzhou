# 服务器、节点与线路

管理页面默认按卡片展示服务器和既有线路，也可切换紧凑列表。服务器详情包括概览、核心、节点、采购用量与有效期、检查记录。服务器和外部上游的采购流量不计入用户套餐总账。

资源关系使用稳定ID与有来源的字段：服务器提供核心实例和入口节点；出口可明确关联执行核心和下一段出口。外部节点属于供应商，不因为执行位置在我方服务器而获得核心控制权限。配置关系不代表认证、TCP、UDP、DNS或整链已经通过检测。

## 导入与兼容

资源导入默认只预览差异。首次映射既有对象必须提供已审核主键和版本，应用还须管理员、写入门禁及当前预览摘要。重复导入不多建资源；已有关系冲突、证据过期或非法链会拒绝。导入不删除缺席对象，不改已有套餐、身份、倍率、账期或流量记录。

`Egress.core_instance` 指定执行核心，`next_egress` 指定已有下一段。最多读取16段并检测环路，异常链不计算截断版本、不显示虚假最终出口，也不开放固定检查。

## 主机观测

`observe_host` 仅采集显式核准的本机物理网卡、CPU、内存和根文件系统。默认每60秒采样，记录180秒后过期；速率只由同世代、同范围、连续有效样本计算。失败保留上次观测和原始时间，不以0代替未知，不从整机累计推算个人套餐用量。

后台只保留本来源最近1440条记录。示例服务见 [host observer](../../panel/deploy/megabox-host-observer.service.example)，包含候选资源限额；实际占用需在目标机器测量，示例不等于可以直接安装。

## 固定检查

`run_resource_checks` 消费管理员提交的固定检查任务。浏览器只能提交允许目录中的目标、版本和动作，不能提供IP、端口、命令或URL。目录由root维护；服务以低权限账号运行，验证目标漂移、并发、幂等、限频、超时和过期租约。

目前固定执行器支持服务状态与不发送业务内容的TCP连接。结果仅适用于所述目标和时间，不替代认证、UDP、DNS或整链验证。页面刷新只读取已有数据，不触发采样、供应商API或检查。示例见 [resource checks](../../panel/deploy/megabox-resource-checks.service.example)。

完整核心配置、升级、Mux、跨机新路径编排和通用轻Agent属于后续能力；资料、观测和检查上线不代表这些功能已完成。
