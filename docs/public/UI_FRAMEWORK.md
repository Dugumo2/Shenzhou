# 固定界面框架

管理端与用户端共用WorkspaceShell；导航来自navigation.ts。新增功能应进入既定分组，不在业务页另建侧栏或随意重排导航。

- 管理导航分业务管理、连接资源；运维槽位未接通时不渲染可点击空页。
- 展开侧栏216px，折叠64px；顶栏56px，内容区24px。菜单单行，不放常驻第二行说明。
- 手机断点800px，导航用抽屉；触达区44px，支持Escape/遮罩/导航关闭、焦点循环和恢复。
- 用户导航为我的服务、使用指南、账号设置；管理员可从账号菜单进入管理面板。菜单隐藏不代替后端鉴权。
- 折叠只保存在组件状态，不持久化用户材料或凭据。

PageFrame以list/detail/operation/import四种类型和heading/actions/filters/summary/tabs/steps/preview/footer插槽表达共同布局。支持可选的加载、空态、错误、过期、未接入、保存及未知结果提示。默认ready；既有业务页仅接壳层和间距，尚未全部改为命名插槽，不将这称为全站模板迁移完成。

服务概览/用量/连接的既定分区及未知计量提示保持不变。前端仍使用实际同源接口；演示数据环境标签不能因美化而删除。
