# 资源统计与页面更新

用户服务的个人套餐账本与其可查看的资源统计保持独立。来源有权限且关联已核验时，服务列表、详情、管理员服务和用量接口提供可选的 `provider_usage`；否则省略该字段，不能沿用旧来源。

资源字段沿用 schema 2，各自包含用量、额度、剩余、周期、到期和采样时间，不合计为个人余额。API额外返回不含秘密的 `source_key`，用于区分绑定与来源版本；磁盘快照格式不因此改变。来源读取失败时 `generated_at` 为 `null`，不能用页面读取时间伪装采样时间。

客户端仅在同一服务、同一已授权来源指纹下，将读取错误与上次已知测量一起显示，并标明失败和原采样时间。首次失败没有旧测量时仍显示未知；来源变更、字段省略或权限失效均清除旧对象。

页面更新只读取已采集快照，不触发供应商API、系统采集或周期重置。概览和用量分区共享一次读取。请求默认15秒超时，同路径和身份的在途读取去重；身份或目标变化取消旧请求，迟到响应不覆盖新会话。

临时网络或服务器错误保留内容；HTTP 401/403/404撤除旧对象，即使错误响应正文异常也保留该权限语义。取消的旧401不影响新会话。页面读取时刻、资源采样时刻分别显示。

验证包含真实页面组件分支、图形保留、权限、异步竞态、来源内嵌错误及桌面/窄屏浏览器检查。通过本地测试不等于已部署或完成核心计量、限额与撤销能力。
