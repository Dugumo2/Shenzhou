# 订阅统计标头与原链接

本地实现关联R05/R06/R08/R14/R25。下载入口复用用户页面的同一套餐投影：已应用额度、当前唯一账期的倍率后消耗、套餐到期和真实采样质量。软件格式只改变配置输出，不新建套餐、身份或额度。

## 数值与缺失

沿用 `Subscription-Userinfo` 的合计约定：`upload=0`、`download=本期倍率后双向总消耗`、`total=已应用套餐额度`、`expire=套餐到期Unix秒`。这里的download不是原始下载量，upload=0也不表示用户没有上传。原始上下行和倍率分解在面板查看。

仅已应用且新鲜、归属完整的数据输出统计标头；未知、部分、缺口、陈旧、没有唯一当前周期、零额度或异常值省略整个标头。未知用量不补0，采购HOME/BWH额度与上游到期不进入标头。已确认的已用0允许表达，超额真实值不截断。

标准字段没有质量、账期起点、下次重置或原始构成。周期切换后只读新活动周期；未取得新周期证据时省略标头，不把旧周期用量当新周期0，也不声称客户端能展示未定义字段。

首样本仅建立累计计数基线，不清空已有账、不证明期初0，也不代表用户放弃旧量。个人期初量和不可恢复历史需单独核实。

## 三条交付链路

| 入口 | 本地行为 | 当前限制 |
| --- | --- | --- |
| 独立订阅下载 `/d/…/` | 原签名、代际、身份和产物核验后，按稳定服务编号读取同套餐标头；GET/HEAD同源 | 不能绕过原下载权限或把隔离产物当生产交付 |
| 旧Django下载 `/s/…/软件` 与辅助资源 `/r/…/资源` | 保留原签名与grant权限；旧会员别名经当前映射读同套餐。没有可靠个人账则省略统计 | 独立旧会员字段不能冒充新套餐账；此入口与原P8 bearer服务不同 |
| 原P8八资源URL | 面板仍按已核来源返回原地址；候选原P8服务读取独立受限套餐快照 | 面板交付JSON不代理下载；仅更新Django不能修改原P8服务的HTTP标头。候选尚未部署 |

原P8候选保留原manifest授权、八地址、原子产物和原生路由转换。采购资源usage.json继续服务原资源采集；套餐另读package-usage.json。快照由同一Django投影生成，绑定固定P8服务编号及原授权manifest摘要，分别核生成时间和真实测量时间。串服务、换代、陈旧、损坏或特殊文件只使统计标头省略，不替换原订阅正文。供应商标题改为固定“神舟云”的合法base64标题，保留服务识别且不拼接外部输入。

快照导出、服务读取和原资源授权属于受信内部路径，没有增加公网管理接口。实际路径、权限、采样频率、服务参数、备份及切换必须列入正式变更清单；快照不能证明核心准确计量、硬限制或旧连接撤销。

## 验证范围

| 软件/资源 | 本地证据 | 真实客户端能力 |
| --- | --- | --- |
| Windows/v2rayN、Android/v2rayNG、SFA原生配置 | 订阅GET/HEAD统计同源、原链接和权限回归 | 导入、更新、统计与标题展示均NOT TESTED，不能用HTTP200代替 |
| 路由、规则、Geo及原Windows原生路由入口 | 原资源授权及正文保留；原P8统计标头只放三个主订阅资源 | 辅助资源不声称支持统计显示 |
| 路由器 | 未改变原不支持状态 | NOT TESTED |

公开后端验证在 `portal.test_subscription_usage_headers`；另有原P8候选假Handler与Django→快照→独立读取器验证。候选未启动监听、未请求真实地址、未修改凭据或部署。POSIX实际权限/符号链接尚需目标系统验证，Windows下的普通文件/硬链接/特殊文件拒绝反例不能替代它。
