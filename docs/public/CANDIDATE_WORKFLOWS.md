# 本地候选规则、用量与演示交付

更新：2026-10-03。此文描述研发候选的实际范围，不代表生产服务已经迁入或可用。

## 服务页面按任务分区

服务详情默认显示“服务概览”，通过“流量用量”和“连接设置”切换任务。流量页面用套餐用量、流量周期表述，详细统计默认收起；它不是付款账单。

连接设置先选设备/系统/软件，选好后收起选择区，只显示该软件的步骤。SFA为完整配置→应用与检查；v2rayN/v2rayNG为节点→路由→应用与检查。候选策略、直连/代理源文件不作为用户平级下载项。演示限制集中提示，导航到下一步不代表设备已经应用。

## 规则管理

管理员的“代理规则”支持新增、编辑、删除、启停，以及域名匹配检查。支持精确域名、域名及子域名和限定域名正则；动作只包含本机直连与当前代理。

- 规范化域名，拒绝重复、同动作覆盖、保护域冲突和不安全正则。
- 相反动作的父子域候选返回警告，匹配解释说明当前代理优先、保护校验及直连候选顺序；基础源尚未接入时，不推断最终线上动作。
- 保存校验修订，重复请求使用幂等回执。结果未知时保留原请求；版本冲突先核对新版本并保留输入。
- 待确认规则请求仅按管理员保存在页面内存；跨组件返回可恢复，整页刷新或应用重启不能恢复。
- 写入只在本地 SQLite IMMEDIATE 模式启用；生产和其他未验证数据库拒绝写入，不调用发布器或生成待执行任务。

候选保存、生产发布、客户端下载与实际应用是不同状态。来源导入、排序、覆盖、方案绑定和生产发布仍未实现。

## 流量概览

用户进入本人服务，可查看已确认扣费、上传、下载、账期、最后采集时间和统计质量。历史支持本期、近7天、近30天，数据库聚合后最多返回90个有记录的入账日期。

服务概览首屏提供额度环图和已确认上传/下载构成；流量分区提供按记录日期的交互柱图，可切套餐用量或原始传输量。统计过期时环图只表示上次确认占比，灰色部分不是可信剩余；缺口/未知不画比例。缺少记录的日期与真实零明确分开。

服务主状态现在按业务原因生成，保留独立应用状态；停用、到期、待应用、耗尽或计量异常不会只显示已应用。管理员“已应用且统计正常”筛选使用相同判据，“计量存在缺口”仅表示缺口，不混称全部未知统计。服务卡显示下次重置；本地新版账号安全表单导航返回新版，保留旧站未开启前端时的行为。

现有账本没有完整的流量发生区间，因此历史明确叫“已确认入账记录”。不会按补报日期声称当天产生了这些流量，不填补零流量日期，也不把不可靠剩余画成进度。只有完整可靠统计和已应用额度同时满足条件时显示扣费进度。

查询只读，不创建账期、身份或任务；沿用本人归属及已核验旧服务映射。服务切换、时段切换和迟到响应不会串入其他服务。

## 合成资源交付

仅在 `PANEL_LIVE=0` 且 `PANEL_CANDIDATE_DEMO_DATA=1` 时开启。使用保留域名的不可连接假节点与当前候选规则，生成 Windows/v2rayN、Android/v2rayNG、Android/SFA 适配演示文件。

本人可获取、复制和下载；重复获取地址稳定，候选规则改变后重新获取更新内容。编译或发布失败保留上一版。下载校验本人会话、服务状态、路径、完整清单和内容摘要；不创建套餐或核心身份。

**演示地址需要本人浏览器登录，不能作为客户端无人值守远程订阅链接。** 真实下载授权、旧链接兼容、真实节点凭据和客户端应用不在本切片范围。基础来源、DNS和二进制Geo资源也尚未接入。

## 接口

统一前缀 `/api/v1`，写操作使用同源会话和 CSRF。

| 方法与路径 | 行为 |
| --- | --- |
| GET/POST `/admin/rules` | 候选列表或创建 |
| PATCH/DELETE `/admin/rules/{id}` | 带修订和幂等键更新或确认删除 |
| POST `/admin/rules/preview` | 域名候选命中解释 |
| GET `/me/services/{id}/usage?period=current` | 本人用量概览与入账记录 |
| GET/POST `/me/services/{id}/delivery` | 读取或获取合成演示资源 |
| GET/HEAD `/me/services/{id}/delivery/{client}/resources/{key}` | 本人下载固定资源键 |

## 验证与限制

本轮公开后端509项测试通过（Windows跳过1项POSIX特有检查），前端41项测试与类型检查、构建通过。另14项依赖未公开现场脚本的测试保持未测。

本机浏览器验证了规则规范化、覆盖拒绝、启停、编辑、删除、子域匹配，用量时段切换和过期统计未知余额，Windows资源实际下载及稳定地址、复制，SFA软件切换获取。浏览器测试使用既有隔离假账号和测试资产。

完整采集与撤销能力仍有已知失败；真实旧资源迁入、生产发布、实际客户端导入、移动端真实视口、多服务及服务授权倍率尚未完成。测试数量不能替代这些验收。
