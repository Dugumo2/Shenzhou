# 套餐用量与时间图

本模块提供本地可验证的“入口累计采样→授权倍率账→自然时间图→用户页面”链路。它不启动真实采集器，不代替核心完整计量、强制限额或连接撤销验收。

## 三种数据

- 用户套餐：同一服务的总额度、本期消耗、剩余、重置和到期；不同软件共用。
- 本人线路明细：套餐总账按线路/入口/当时授权倍率的分解；中转后续跳不再次扣减。
- 采购资源：管理员独立端点admin/resource-usage读取已采集来源；不返回到本人或管理员订阅额度列，也不相加成用户余额。

## 持久计量

0019只添加结构，不改写原账。ServiceRateVersion按服务、线路和入口追加倍率；UsageLedger保留旧rate_version，并新增grant_rate_version和interval_start/interval_end。

IngressUsageSample保存累计值、发生区间前锚、代际、序号、指纹、覆盖状态，以及非秘密服务器/线路/入口/交付/身份代际归属快照。record_ingress_sample是受信内部调用，不是公网写接口；来源必须明确声明累计计数与已核覆盖，不能从数值自动推定完整。

首样本只建基线，不追扣迁入前累计。同序号同内容重放不写；异内容拒绝。身份归属漂移不能通过换epoch绕过。实际区间完整落入唯一已存在账期才扣减；倍率或周期边界缺证据时保留gap，不均摊、不创建账期。完整、可归属的迟到旧期区间可归旧期，原入库日不当发生日。

额度扣减使用入口上传+下载乘当时服务授权倍率，保存整数百万分母余数。切入新路径后同一身份拒绝旧计量路径，避免重复扣账。真实核心的计数准确性和未采尾部需要采集端另行证明。

## 查询与页面

本人usage接口支持period=7d/month/year，返回schema_version=2以及timeseries、line_usage；原current/30d入账记录查询保留兼容，但用户页面默认7d。

近7天包含今天前6日；本月按自然日；今年按12个月。业务时区Asia/Shanghai。已测零、没有记录、尚未到来分别表达；不能从单点累计生成历史。概览是一份套餐圆环和原始上下行构成，时间页是独立柱图。

跨日/月无法细分的已确认区间只计入完整覆盖它的范围合计与unallocated一次，不塞进某天。只相交查询边界的记录标待核，不猜部分金额。unallocated每页最多100条，签名cursor绑定服务、范围、水位和15分钟有效期，总量不随分页改变；线路明细同水位。

统计只差最近三分钟内正在采样的尾部且此前连续时，message_code=sampling_pending；金额仍是已记录部分，不伪装完整。中间断档、缺身份或过期样本不会使用此提示。旧账没有发生区间则不进入新自然时间图。

SQLite查询采用DEFERRED读快照，避免为GET申请写预留锁；恢复连接原事务模式。聚合流式处理，没有截断总量；大规模全年账本查询耗时仍需实测，当前没有预聚合。

## 本地验证

计量、独立归属反例、自然时间桶和API分别由portal.test_ingress_metering、test_ingress_metering_review、test_usage_timeseries、test_usage_views_api覆盖。前端测试实际挂载用户列表/详情/时间图，验证权限清空、迟到响应、范围与明细一致、缺失和未来。

本地隔离数据和截图不证明现网已接入；旧共享计数、供应商API总量不得作为用户账本初值。发布需要确定真实身份与套餐归属、覆盖范围和原稳定链接的兼容清单。
