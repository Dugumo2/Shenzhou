# 面板代码：待整改研发基线

这是原有Django候选源码，保留迁移、规则生成与隔离测试基础，并非下一版成品。

目标行为见[用户效果方案](../docs/panel/USER_OUTCOME_PLAN_20261001.md)，运行方式见[开发说明](../docs/public/DEVELOPMENT.md)。

当前仍包含全局线路倍率、每用户单服务、旧容量菜单、旧模板品牌等需要整改的实现。现有测试只证明其各自覆盖的旧行为，不能证明它们符合新合同。逐用户持久计量和存量连接撤销没有通过全部能力门槛，生产执行器允许集保持为空。

`bridge/vendor`是本项目既有生成器的内部复制，不是从调研的第三方面板复制的代码。公开基线将历史站点/IP换成保留示例值，并保留原来的严格作用域校验；这些示例值不是部署配置。真实现场版本在原工作区受限备份中保留，不随仓库发布。禁止直接把示例版覆盖生产。

`tests/probe_*.py`属于另需核心二进制、固定环境与运行参数的历史实验，不是普通单测命令的一部分。该仓库不携带核心二进制或实验秘密。生产部署脚本尚未纳入公开基线。

协议生成代码 `bridge/proto` 因来源/许可记录尚未补齐，未纳入首次公开范围；依赖它的历史探针不能从本仓库直接运行。普通Django测试不依赖该目录。
