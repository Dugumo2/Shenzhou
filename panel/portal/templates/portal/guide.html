01 / 先了解

先选出口身份，再选接入协议

HOME

住宅出口

通过搬瓦工中转，再经当前住宅上游访问网站。日常可从 HOME-Reality 开始。

住宅或住宅 DNS 失败时，请求失败，不自动换到 BWH 或本地网络。
BWH

搬瓦工出口

由搬瓦工访问网站。只有选择 BWH 时，已批准的媒体服务才使用服务器的 AKDNS。

BWH 不是住宅；客户端的“直连”则是使用设备本地网络，含义不同。

Reality、HY2、WS、AnyTLS 表示连接中转服务器的不同方式。切换同一身份下的协议通常不改变出口；自动组也只在同一身份内选协议，不能把一台中转当成多条独立线路。

客户端交付内容自动组
Windows · v2rayN8 个普通节点2 个自动选择项，随专属订阅提供
Android · v2rayNG6 个普通节点，不含 AnyTLS2 个原生组，需在手机手动创建一次
Android · SFA完整远程配置，内含 8 节点内含 2 个同身份自动池

指南依据 2026-09-22 的交付记录：v2rayN 7.24.9、v2rayNG 2.2.6、SFA 核心 1.14.1。其他版本的菜单或兼容性需要单独核对。面板不会替你控制客户端 TUN、VPN 或当前节点。

02 / WINDOWS

v2rayN：八节点 + 两个自动项

电脑

  1. 添加 Windows 专属订阅

    在“我的订阅”复制 Windows 节点订阅地址。打开 v2rayN 的订阅分组设置，新建名为 Megabox 的分组，填入地址并保存，再更新订阅。已有 Megabox 时更新原分组即可。

    检查 HOME、BWH 各有 Reality、HY2、WS、AnyTLS，并有 HOME-Auto、BWH-Auto。不要将 Android 完整配置或旧 Custom 配置贴入此处。

  2. 核对规则与 DNS

    节点订阅只提供节点和自动项。现有项目电脑已单独安装规则资源与原生 DNS 设置；新电脑需要完成相同适配，不能仅导入节点便认为配置齐全。

    日常选择 HOME-Reality，上方“当前代理 → 规则模式”选规则，下方路由选 P8-绕过大陆(Whitelist)。不要同时套用另一份旧规则。

  3. 按需要开启客户端接管

    系统代理使用“自动配置系统代理”；需要整机接管时，在客户端操作原生 TUN。系统代理、TUN 和路由模式分别控制不同环节。此网页无法开启这些开关。

    本指南曾核验 v2rayN 7.24.9 + sing-box 1.13.21 的 DNS 与 TUN 适配，仅说明当时已检查的版本组合。你现在安装的版本以客户端“关于 / 核心版本”为准；更换核心或新设备前先核对兼容性。

  4. 重新建立连接，再检查

    关闭旧网页连接后重开，分别检查需要代理的应用和国内网页。旧连接可能延续旧路径；仅看到延迟数字或订阅更新成功，不能证明实际应用已经可用。

“规则”“全局”“直连”怎么选？
上方模式作用
规则使用下方选定的原生路由表；日常通常使用绕过大陆。
全局优先走当前节点；选 BWH 时仍是 BWH 出口，不会自动变成住宅。
直连业务和对应 DNS 走电脑本地网络。

下方“P8-全局”是路由表，上方“全局”是核心模式，两者不要混淆。客户端左侧出现 GLOBAL 字样，也不能单独证明当前使用全局模式。

怎样正常停止代理？

只停系统代理：选择“清除系统代理”。如果 TUN 仍开启，还需关闭原生 TUN。完全退出时使用托盘菜单“退出”，不要用强制结束进程替代。

旧 Windows Guard 已撤销，不要按历史指引重新启用或恢复它。当前原生 TUN 不代表额外的退出断网保护。

03 / ANDROID · V2RAYNG

六个节点，两个自动组手动建

手机

先停止 SFA 或其他 VPN。以下是 v2rayNG 2.2.6 的原生功能流程；不要导入 Windows 专用策略组或 SFA JSON。

  1. 导入六节点订阅

    复制“我的订阅”中的 v2rayNG 地址。在侧栏“订阅分组设置”点加号，名称填 Megabox，粘贴地址并保存。返回主页更新订阅，确认 HOME/BWH 各有 Reality、HY2、WS，共六个普通节点。

  2. 单独设置原生 DNS

    在设置中开启“启用本地 DNS”，关闭 FakeDNS / 启用虚拟 DNS。将“远程 DNS”填为下面这一项：

    tcp://8.8.8.8:53

    填在“远程 DNS (udp/tcp/https/quic)”中，不要填入只接受 IP 的“VPN DNS”框，也不要使用 tcp+local://。这里“本地 DNS”指手机 Xray 模块接管查询，不是指定运营商 DNS。节点订阅更新不会替你设置这一项。

  3. 登记两份固定资源链接，再导入小路由表

    使用管理员交付的两条固定资源下载地址，分别对应 megabox-geosite.dat 与 megabox-geoip.dat；它们与六节点订阅地址不同。进入“资源文件 → 添加 → 添加链接”，将别名准确填写为对应文件名，粘贴各自地址并保存。

    在资源页点击“下载文件”完成获取，以后也在这里更新资源。v2rayNG 2.2.6 的按钮会批量下载已登记资源，包含默认资源；项目路由仍只引用自己的两份 DAT。该下载器在代理下载失败时可能尝试直接下载，这是资源下载行为，不代表 HOME 业务可以回退到本地网络。

    首次添加链接或调整已存在的同名资源前，先保留旧 DAT 与路由备份并停止 NG。不要重复添加同名项；编辑资源 URL 可能移除旧本地文件，需要成功下载后再启动。也可用“添加文件”导入离线 DAT，作为下载失败时的回退。确认文件名准确、大小非零；不要把完整大名单复制进剪贴板。

    在“路由设置”先导出旧规则。检查并解锁会冲突的旧 UDP443 阻断或固定出口项。打开本项目 v2rayng-routes.json，复制从 [ 到 ] 的完整小型 JSON，再点“从剪贴板导入规则集”。应复制文件内容，不是它的下载地址。

    确认没有旧通用 UDP443 阻断抢在前面。受保护业务优先代理，大陆集合直连，其余走当前节点。路由中的 ext:megabox-… 引用刚导入的两份资源。

  4. 在“所有”标签创建两个自动组

    主页切到所有标签；若没有，在设置中开启“启用显示所有组”。点右上加号 → “添加 [策略组]”，按下表分别建立两组。

    字段住宅自动组BWH 自动组
    别名HOME-AutoBWH-Auto
    策略组类型最低延迟最低延迟
    来自订阅分组MegaboxMegabox
    别名正则过滤^HOME-(Reality|HY2|WS)$^BWH-(Reality|HY2|WS)$
    ^HOME-(Reality|HY2|WS)$
    ^BWH-(Reality|HY2|WS)$

    不要停留在 Megabox 订阅标签里创建组，否则更新订阅可能删除组本身。在“所有”页创建，成员来源仍选 Megabox，每组应匹配三个节点。普通订阅无法自动创建这两组。

  5. 先选 HOME-Reality，短测日常应用

    保存设置，停启 NG 并按手机提示允许 VPN。先试 ChatGPT、学校 cuit.edu.cn、QQ 图片和国内网页，再尝试其他节点或自动组。不要同时开启两款 VPN。

    若曾只让浏览器等少数应用进入 VPN，其他应用不会自动受这份规则控制。需要整机分流时，在不影响当前工作的时段核对“启用分应用”选项，再停启客户端。

i

已知反馈：HOME-Reality 在修正 DNS 后使用流畅。其余五节点、手机原生自动组、完整新路由、切网与后台表现仍需逐项实测；不能由服务器检查结果代替。

04 / ANDROID · SFA

一份远程配置，八节点 + 两个自动池

手机

  1. 添加专属远程配置

    停止 NG 或其他 VPN，打开 sing-box for Android，在配置页新增，类型选“远程 / Remote”，名称填 Megabox。粘贴 SFA 专属地址，保存并更新。已有配置时更新原项即可。

  2. 选择配置与出口

    启用这一个配置并确认 Android VPN 权限。日常选 HOME-Reality + Rule。HOME/BWH 各四节点，HOME-Auto 与 BWH-Auto 分别只在各自身份内选择。媒体仅在选 BWH 时使用服务器已批准的 AKDNS。

  3. 重新启动并检查实际使用

    远程配置包含节点、DNS 和路由，更新后需要停止并重新启动才能加载。当前版本已加入网络接口自动检测修正，但这不等于手机发热或闪退问题已经完全解决。

    短测 ChatGPT、QQ 图片和国内网页。出现异常时，停止 SFA，回到此前可工作的 NG；不要额外开启“允许绕过 VPN”或托管分应用排除等未核验选项。

停止 VPN 后手机仍不能联网？

在 Android 系统设置搜索“VPN”，检查该客户端是否开启“阻止未使用 VPN 的连接”或“始终开启 VPN”。当前交付不要求开启这些附加选项；不需要持续自动连接时应按自己的用途核对并关闭。

网页无法读取或更改手机的这些开关。停止后的联网、锁屏和切网行为需要在手机实际验证。

v2rayNG 的名单怎样安全更新？

用官方“添加链接”登记两条固定资源 URL 后，不必每次删文件重导。保留可用 DAT 与小路由备份，在资源页点击“下载文件”更新，再核对 megabox-geosite.dat 与 megabox-geoip.dat 均成功下载，重新启动客户端。此按钮批量更新登记资源，节点订阅更新不会代替它。

下载失败时不要先删除可用旧文件；若资源已经丢失或不能加载，保持 NG 停止，用“添加文件”恢复旧 DAT 和旧小路由。只有继续采用离线文件方式时，才需先下载齐新文件、停止 NG，再替换两份同名自建资源。保留内置资源，不在运行中先删文件。

不要重新导入 NG 内置 Global/Whitelist 预设，它们可能替换当前规则并恢复通用 UDP443 阻断；需要全局或黑名单时使用项目对应的原生路由文件。

怎样看流量？

面板分配给账号的额度、按用户计量、住宅套餐和 BWH 套餐是不同数据。数据尚未接入时，不应把面板中的参数或零值当作实际剩余流量。

住宅统计是自累计起点以来的估算，不含起点前未知历史，不能冒充供应商账单余额。BWH 使用供应商已计费双向数据；同一 HOME 请求会经过两边，不能把两项相加作为独立可用余额。

v2rayN 7.24.9 不显示本项目套餐标头，其“流量统计”只是本机统计；SFA 的用量卡片显示仍未实机核验。管理员可按已部署的套餐查询入口核对来源与采集时间。

订阅链接轮换后要做什么？

本面板为 Windows、SFA、v2rayNG 分别签发地址，当前“轮换全部订阅链接”会同时更新三类设备授权。逐一复制新地址，更新对应客户端后刷新订阅，并核对规则资源地址；不要先删除唯一可用配置。

旧版服务器订阅中的 SFA 与 NG 曾共用 Android 授权，不要把旧版关系套用到本面板。修改登录密码、轮换下载链接和撤销已下载的节点凭据是不同操作；链接轮换不会让已下载节点自动失效。只有已发布的真实配置会显示地址。

06 / 遇到问题

先分清是哪一步，再调整

01

登录或订阅不可用

检查账号状态、有效期、订阅是否已开通，以及是否刚轮换过链接。保留现有可用配置，向管理员说明错误时间和客户端名称，不发送完整订阅链接。

02

有延迟，网页打不开

延迟探测不等于完整应用请求。确认所选 HOME/BWH 身份、DNS 设置、规则资源和路由，然后用新连接检查。HOME 故障时不要把自动切 BWH 当作修复。

03

个别应用与其他应用不同

核对系统代理、TUN/VPN 和分应用设置是否覆盖该应用。应用自带 DNS、已有连接和缓存可能影响路径；单次 IP 查询无法证明全部流量都符合预期。

04

更新失败

保留最后可用配置与规则，检查下载和权限问题。不要删除活动配置、关闭证书校验，或改成无条件本地直连来绕过错误。

实际播放、账户可用性、UDP、IPv6、锁屏与切网表现都需要单独验证。已完成某项配置检查，不代表这些场景全部通过。
